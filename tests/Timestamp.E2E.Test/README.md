# E2Eテスト

## テスト方針

このE2Eテストは、`dotnet-timestamp` CLI ツールを実際のプロセスとして起動し、標準出力、標準エラー、終了コードを検証します。

### 実行方法
- `dotnet run --project <path-to-Timestamp.csproj> -- <args>` を使用して実プロセスとして実行
- タイムアウト: デフォルト60秒
- すべてのテストはリポジトリルートから実行

### テスト構成
- **ProcessRunner**: 外部プロセスの起動と出力キャプチャ
- **TimestampCliRunner**: `dotnet run` ベースのヘルパー
- **各コマンドテストクラス**: 機能別にテストを分離

## テスト内容

### ルートコマンド

デフォルト動作（コマンド指定なし）のテスト。`now` コマンドと同等の動作を検証します。

**テストケース:**
- 引数なしで現在日時をISO 8601形式（デフォルトフォーマット `o`）で出力
- `--format` オプションでカスタムフォーマット指定（例: `yyyy-MM-dd`）

**検証項目:**
- 終了コード: 0
- タイムアウトしないこと
- 出力が有効なタイムスタンプであること
- 指定フォーマットに一致すること

### nowコマンド

現在日時を表示するコマンドのテスト。

**テストケース:**
1. **基本動作**: オプションなしで現在日時を表示
2. **カスタムフォーマット**: `--format` (または `-m`) でフォーマット指定
3. **タイムゾーン指定**: `--timezone` (または `-z`) で表示タイムゾーン指定
4. **複合オプション**: フォーマットとタイムゾーンの同時指定

**検証項目:**
- 終了コード: 0
- 出力フォーマットの正確性（正規表現による検証）
- タイムゾーンオフセットの正確性（例: Tokyo Standard Time = UTC+9）

**使用例:**
```bash
dtstamp now --format yyyy-MM-dd --timezone "Tokyo Standard Time"
```

### timezoneコマンド

タイムゾーン情報を表示するコマンドのテスト。

**テストケース:**
1. **ローカルTZ表示**: オプションなしでシステムのローカルタイムゾーンを表示
2. **一覧表示**: `--list` (または `-l`) で利用可能なタイムゾーン一覧を表示

**検証項目:**
- 終了コード: 0
- ローカルTZ: タイムゾーンID表示
- 一覧表示: 
  - "UTC" を含むこと
  - "Standard Time" を含むこと
  - 10件以上のエントリがあること

**使用例:**
```bash
dtstamp timezone          # ローカルTZ表示
dtstamp timezone --list   # 一覧表示
```

### convertコマンド

日時をタイムゾーン間で変換するコマンドのテスト。

**テストケース:**
1. **基本変換**: 必須オプション（`--datetime`, `--from`, `--to`）での変換
2. **短縮オプション**: `-d`, `-f`, `-t` による変換
3. **カスタムフォーマット**: `--format` (または `-m`) で出力フォーマット指定
4. **日付境界処理**: 日付をまたぐ変換の正確性
5. **ISO 8601入力**: オフセット付き日時の変換

**検証項目:**
- 終了コード: 0
- 変換後のタイムゾーンオフセットの正確性
- 時刻計算の正確性（例: UTC 12:00 → JST 21:00）
- 出力フォーマットの正確性

**使用例:**
```bash
dtstamp convert --datetime "2026-01-12T12:00:00" --from UTC --to "Tokyo Standard Time"
dtstamp convert -d "2026-01-12T12:00:00+09:00" -f "Tokyo Standard Time" -t UTC -m yyyy-MM-dd
```

### エラーハンドリング

不正な入力や必須パラメータ不足時の動作を検証。

**テストケース:**
1. **必須パラメータ不足**: `--datetime`, `--from`, `--to` のいずれかが欠けている場合
2. **不正な日時**: パース不可能な日時文字列
3. **不正なタイムゾーン**: 存在しないタイムゾーンID
4. **未知のコマンド**: 定義されていないコマンド

**検証項目:**
- 標準エラー出力にエラーメッセージが含まれること
- ※終了コードは現在0を返すため、実装側の改善が必要（TODO）
